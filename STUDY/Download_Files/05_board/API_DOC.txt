url : /list/{page}
method : GET
예시 : /list/1
설명 : 특정 페이지의 list 가져오기(페이지당 5개)
응답 : 
{
  page: 1,
  pages: 10,
  list:[
    {idx:1, subject:'간단한제목', bHit:0, user_name:'관리자'},
    {idx:2, subject:'간단한제목', bHit:0, user_name:'관리자'},
    {idx:3, subject:'간단한제목', bHit:0, user_name:'관리자'},
    ...
  ]
}


url : /detail/{idx}
method : GET
예시 : /detail/123
설명 : 특정 idx 의 게시글 가져오기
응답 : 
{idx:123, subject:'간단한제목',content:'간단한 내용', bHit:0, user_name:'관리자'}


url : /delete/{idx}
method : GET
예시 : /delete/123
설명 : 특정 idx 의 게시글 삭제하기
응답 : 
{idx:123, success:true}


url : /write
method : POST
예시 : /write
{user_name:'admin', content:'test content', subject:'test subject'}
설명 : 글쓰기
응답 : 
{idx:324, success:true}
