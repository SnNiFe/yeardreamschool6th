객체지향언어(Object Oriented Programing)
소스코드를 부품처럼 여겨서 조합하여 프로그램을 만드는 개념
하나의 객체 == 기능을 갖은 소스 뭉치

1. class(classification)
소스들을 잘 분류하기 위해 만들어진 개념
class 안에는 특정 속성과 메서드 들이 있음 이를 대표할 수 있는 이름이어야 한다.
- 사용시 객체화(복사개념)를 하여 사용 한다.
- 특정한 경우 원본을 직접 사용할 수 있다.(static 키워드가 있어야만 가능)

2. OOP 4대 특징
캡슐화(Encapsulation)
- 사용자에게 공개하거나 수정하게 할수 있는 내용을 제한
- 예) 컴퓨터 - 전원, 팬, 온도 등등... (케이스로 감싸고 일부를 알려주는..)

상속(Inheritance)
- 부모의 것을 내것처럼 이용하는 개념
- 부모의 매세드를 사용할때 부모를 객체화하지 않고 자식만 객체화하여 사용 가능

추상화(Abstraction) - js 에는 없는 개념
- 여러 클래스들의 공통된 내용을 추출 하여 단순화 하는 개념
- 예) 약도, 캐리커쳐
- 이것만큼은 꼭 있어야 한다는 최소의 기능/표준

다형성(Polymorphism) - js 에는 없는 (굳이 알 필요가 없는) 개념
- 하나의 부모안에 여러 자식이 대입될 수 있는 개념
- 변수 선언과 사용을 효율적으로 하기 위해 사용 한다.
- JS 나 python 에서는 이미 다형성이 적용된것이나 마찬가지
