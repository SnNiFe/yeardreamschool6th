- schedules.json

QR리더의 자동 실행 시간 저장 기록 파일
없으면 시간 설정 시 자동 생성 됨

=================
이미지 열기 : QR 이미지를 열어 링크 표시
클립보드 읽기 : QR 이미지를 클립보드에서 열어 링크 표시
1회 전체 스캔 : 현재 화면의 QR의 링크 표시
영역 지정 캡쳐 : 특정 구역의 QR의 링크 표시
자동 감시 설정 : 자동으로 해당 시간 내 전체 스캔
    시작 : 시작 시간을 HH:MM 에 맞게 작성
    종료 : 종료 시간을 HH:MM 에 맞게 작성
    추가확인 : 추가로 반복하여 감시할 횟수 작성
    반복 요일 : 감시할 요일 조건 추가
    URL 필터 : QR 링크 실행 할 페이지 조건 추가
+추가 버튼으로 추가 가능
-선택된 시간 삭제 버튼으로 삭제 가능
    감시 주기(초) : 해당 초 마다 전체 스캔
*자동 감시 시작 버튼으로 감시 시작
=================
